# 🌍 MÉDINA BAYE — À la découverte de la cité religieuse

## 📌 Présentation du projet

**Médina Baye** est un site web développé avec Django dans le but de faire découvrir Médina Baye, une importante cité religieuse située à Kaolack, au Sénégal.

Ce projet met en valeur son histoire, son patrimoine religieux, sa culture et ses traditions à travers une plateforme web accessible et conviviale.

## 🎯 Objectifs

- Faire découvrir l'histoire de Médina Baye.
- Présenter son patrimoine religieux et culturel.
- Valoriser ses traditions et ses pratiques spirituelles.
- Faire connaître les événements religieux et culturels.
- Faciliter l'accès à l'information sur la cité.

## ✨ Fonctionnalités

- **Accueil :** présentation générale de Médina Baye.
- **Histoire :** découverte de l'histoire de la cité et de son développement.
- **Culture et traditions :** présentation des écoles coraniques, du Wazifa, du Khadara, du Maouloud, des dahiras et des ziars.
- **Patrimoine :** découverte des lieux et éléments importants du patrimoine.
- **Galerie :** collection de photographies illustrant la cité.
- **Contact :** espace permettant aux visiteurs de prendre contact.

## ⚙️ Installation et exécution

1. Cloner le dépôt :

```bash
git clone https://github.com/matynd26-debug/Medina_Baye_Django.git
```

2. Accéder au dossier :

```bash
cd Medina_Baye_Django
```

3. Créer un environnement virtuel :

```bash
python -m venv .venv
```

4. Activer l'environnement virtuel sous Windows :

```bash
.venv\Scripts\activate
```

5. Installer Django :

```bash
pip install django
```

6. Effectuer les migrations :

```bash
python manage.py migrate
```

7. Lancer le serveur :

```bash
python manage.py runserver
```

Le site sera accessible à l'adresse : http://127.0.0.1:8000/
